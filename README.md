# E-Commerce Backend (Django)

RESTful backend for an e-commerce application built with Django and Django REST Framework. Designed to be consumed by a React frontend.

## Features
- User authentication
- Product and category APIs
- Cart and order management
- API integration for frontend

## Tech Stack
- Python
- Django
- Django REST Framework
- SQLite / PostgreSQL

## Setup
1. Create virtual environment  
2. Install dependencies  
3. Run migrations  
4. Start server

## Status
Backend completed and tested with frontend integration.
